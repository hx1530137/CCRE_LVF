# Reference Results

This directory contains compact JSON summaries from the latest v3 runs:

- `v3_main_results.json`: main test-set comparison;
- `v3_cross_dataset_results.json`: cross-dataset evaluation;
- `v3_ablation_results.json`: LVF component ablations.

These files are reference outputs. Full reproducibility requires the released dataset, the specified model checkpoints, and the runtime configuration described in the top-level README.
