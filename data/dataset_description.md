# 数据集说明

## 1. 主测试集: sanguo_test

- **文件路径**: `sanguo_test_filtered_final.json`
- **来源**: 基于三国志古文生成的问答对
- **规模**: 1480条查询, 1023个唯一文档
- **格式**:
```json
{
  "instruction": "建安某年九月，曹公进军至新野县后，当地局势有何变化？",
  "input": "参考文献：\"三国志卷一 魏书一 武帝纪第一\n\n古文：十四年春三月，军至谯，作轻舟...\n现代文：建安十四年春三月，曹军到了谯县...",
  "output": "答案文本"
}
```
- **特点**: 查询是基于文档内容生成的现代文问题，不是文档的子串，具有真实的检索难度

## 2. 微调训练集: sanguo_train

- **文件路径**: `qwen3-emb-finetune/data/emb_train_data_clean_train.jsonl`
- **规模**: 12654条
- **格式**(JSONL):
```json
{
  "messages": [{"content": "现代文查询"}],
  "positive_messages": [[{"content": "古文+现代文拼接文档"}]]
}
```
- **数据泄露检查**: 训练集查询与测试集查询无重叠（sanguo_test: 0/1480, zhengliban: 0/500）

## 3. 跨数据集: 史记

- **文件路径**: `史记合并-with-prompt-api-response-extracted-train.json`
- **规模**: 17362条（实验取1/10 = 1736查询, 427文档）
- **格式**: 同sanguo_test（instruction/input/output）
- **特点**: 不同史书的泛化性验证

## 4. 跨数据集: 汉书

- **文件路径**: `汉书合并mini-with-prompt-api-response-extracted-train.json`
- **规模**: 25566条（实验取1/10 = 2556查询, 714文档）
- **格式**: 同sanguo_test

## 5. 跨领域数据集: history-10k

- **文件路径**: `classical_history_retrieval_10k.json`
- **来源**: HuggingFace `flowerone/chinese-classical-corpus` 的c2m（古译今）任务
- **筛选**: 史书类（列传/本纪/志），古文长度>15
- **规模**: 10000条（实验取1/10 = 1000查询, 1000文档）
- **覆盖**: 明史/宋史/后汉书/新唐书/魏书/史记/北史等15+史书
- **格式**:
```json
{
  "instruction": "后来他把这话告诉了尚书令王俭，王俭心里更感到诧异...",  // 现代文翻译（查询）
  "input": "后以语尚书令王俭，俭意更异，乃以爲太子中庶子，领左卫率。",  // 古文原文（文档）
  "source": "南史·列传/卷四十七",
  "category": "史"
}
```
- **特点**: 跨语言检索（现代文翻译→古文原文），翻译对语义高度对应，Vector R@1接近天花板(0.987)

## 6. 跨领域数据集: C3bench-crosslang

- **文件路径**: `C3bench_crosslang_1000.json`
- **来源**: HuggingFace C3_bench (古文多领域知识问答基准)
- **原始规模**: 10000条（覆盖10个领域）
- **实验规模**: 1000查询, 1000文档（1/10采样，固定seed=42）
- **领域分布**: 儒(198)/史(197)/道(98)/诗(98)/佛(94)/医(91)/兵(65)/农(63)/法(51)/艺(45)
- **来源**: 伤寒论/齐民要术/百战奇略/明史/宋史/韩非子/列子/孙膑兵法等
- **格式**:
```json
{
  "instruction": "威王问， 如果我军和敌军兵力为一比十时，有攻击敌军的办法吗？",  // 现代文查询
  "input": "威王曰： 以一击十，有道乎？",  // 纯古文文档（无现代文翻译）
  "source": "孙膑兵法",
  "category": "兵"
}
```
- **特点**:
  - **跨语言检索**: 查询是现代文，文档是纯古文（去掉了现代文翻译），字符重叠率仅0.43
  - **多领域覆盖**: 涉及儒/道/佛/医/兵/法/农等10个与史书不同的领域
  - **检索难度**: BM25 R@1仅0.59（跨语言词汇不匹配），Vector R@1=0.963
  - **数据泄露检查**: 与sanguo_test查询零重叠（0/1480）

## 7. 数据集统计对比

| 数据集 | 查询数 | 文档数 | 查询类型 | 文档格式 | Vector R@1 | BM25 R@1 |
|:------|:------:|:------:|:--------|:--------|:----------:|:--------:|
| sanguo_test | 1480 | 1023 | 问答 | 古文+现代文拼接 | 0.78 | 0.76 |
| 史记(1/10) | 1736 | 427 | 问答 | 古文+现代文拼接 | 0.71 | 0.76 |
| 汉书(1/10) | 2556 | 714 | 问答 | 古文+现代文拼接 | 0.69 | 0.74 |
| history-10k(1/10) | 1000 | 1000 | 翻译对 | 古文+现代文拼接 | 0.99 | 0.81 |
| **C3bench-crosslang** | **1000** | **1000** | **问答** | **纯古文** | **0.96** | **0.59** |

**关键区别**:
- 问答格式数据集（前三个）查询是基于文档生成的问题，检索有真实难度
- history-10k翻译对查询是文档的现代文翻译，语义高度对应，Vector接近天花板
- C3bench是纯跨语言检索：查询是现代文，文档是纯古文，BM25因词汇不匹配失效(0.59)，LVF通过向量+词汇验证弥补了这一缺口
